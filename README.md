# Swimming Pool Ticket Management System

Fundamentals of Programming Final Exam · T1A Group 01 · Universitas Brawijaya

## Project Proposal

This project extends the midterm swimming pool ticket calculator into a TypeScript console application. Ticket counter staff will be able to calculate prices based on the day, visitor category, and membership. They will also be able to keep track of ticket sales while the program is running.

## Planned Features

- *Create* — Calculate the ticket price and record the sale.
- *Read* — View all sales or look up a sale by transaction ID.
- *Update* — Edit a sale and recalculate the price if needed.
- *Delete* — Remove a sale after confirmation.
- *Search* — Find sales by buyer name and filter them by day type.
